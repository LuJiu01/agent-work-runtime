# Team V1 known limits

Automated PostgreSQL tests cover protocol behavior for the 69 required
scenarios. They are not a substitute for:

- two distinct real Agent clients completing collaboration, handoff, review
  and acceptance on one live Team project
- a measured production SLA
- multi-region high availability

Capacity probes record actual local rates. They must not be quoted as
enterprise throughput. This tree does not push a release tag.
